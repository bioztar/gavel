gavel extension — fixtures

Static pages shaped like the two Google surfaces the extension injects into, served by mock/server.mjs. Load the dev build (dist-dev/) as an unpacked extension and open one of these; the "Chair this meeting" control appears next to the Save / Join button.

  • Calendar editor — new, unsaved event (agenda is written into the page's description field)
  • Calendar editor — existing event (agenda is written through the mock Calendar API)
  • Meet pre-join screen (event found by Meet code, written through the mock Calendar API)
  • Registered agendas (JSON)

Briefs to try: "Weekly sync with the team" gets the refusal gate. "Decide whether we ship Thursday. Pricing — Ana, 10 min. Rollout — Artem, 15 min." gets an agenda.
